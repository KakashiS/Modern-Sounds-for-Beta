This small mod adds missing sounds to Beta 1.7.3, such as:

Submerging and surfacing sounds
Underwater sound
Furnace sound
Minecart sound
Boat sounds
Fall sounds
This mod includes original audio assets created by Mojang Studios / Microsoft for modern versions of Minecraft. All sound effects belong to Mojang Studios and their respective sound designers. This project is not affiliated with or endorsed by Mojang Studios or Microsoft.
